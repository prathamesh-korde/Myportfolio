# Profile Picture Setup

To add your profile picture to the portfolio:

1. **Place your image** in this `public` folder
2. **Rename it** to `profile.jpg` (or update the src in About.jsx)
3. **Recommended specs:**
   - Square image (1:1 aspect ratio)
   - Minimum 500x500 pixels
   - JPG or PNG format
   - Professional headshot or photo

The image will automatically appear in the About Me section with a blue border and shadow effect.

If no image is found, it will show a default emoji placeholder.
