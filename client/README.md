# Portfolio Client

React + Vite frontend for the MERN portfolio example.

## Setup (PowerShell)

```powershell
cd client
npm install
npm run dev   # starts Vite dev server on http://localhost:3000
```

Make sure the backend server is running on port 5000.

## Features

- Responsive navbar & footer
- Home hero with CTA buttons
- About page with skills progress bars
- Projects page (fetches from backend API)
- Experience timeline UI
- Contact form (submits to backend API)
- Smooth animations with Framer Motion
